# Portfólio — Analista de Dados

Portfólio pessoal desenvolvido com React + Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal.

## Gerar versão de produção

```bash
npm run build
```

A versão final ficará na pasta `dist`.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie este projeto para o repositório.
3. Acesse **Settings → Pages**.
4. Em **Source**, escolha **GitHub Actions**.
5. O workflow incluído em `.github/workflows/deploy.yml` fará o deploy.

## Onde editar suas informações

O arquivo principal para personalização é:

`src/data.js`

Nele você pode alterar:

- nome;
- cargo;
- LinkedIn;
- GitHub;
- e-mail;
- competências;
- projetos;
- experiência.

## Antes de publicar

Troque o e-mail de exemplo em `src/data.js`.
Também é recomendado substituir os links gerais do GitHub por links específicos de cada repositório.
